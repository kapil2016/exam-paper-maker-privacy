# Exam Paper Maker — privacy policy

The privacy policy for the Android app **Exam Paper Maker**
(`com.craftexampaper`), published by appcraftstudio.

Live at <https://kapil2016.github.io/exam-paper-maker-privacy/>, which is the
URL given to Google Play under *Policy → App content → Privacy policy*.

## Changing it

`index.html` is the whole site. The master copy lives with the app source in
`app_realese/privacy-policy.html`; edit it there, copy it over `index.html`
here, then:

```sh
git add -A && git commit -m "Update privacy policy" && git push
```

GitHub Pages rebuilds within a minute. Change the "Last updated" date at the
top of the page whenever the policy itself changes — a policy whose date never
moves is one nobody believes.
